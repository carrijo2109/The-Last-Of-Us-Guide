# The Last of Us — O guia do jogo

Site de fã, responsivo e feito em um único arquivo HTML (sem dependências além das fontes do Google Fonts).

## Recursos
- Abertura com cenário em SVG, paralaxe e lanterna que segue o cursor
- Cartas de personagens que viram ao clique
- Abas com os tipos de infectados
- Linha do tempo expansível
- Quiz rápido
- Tema claro e escuro automático

## Como usar
Abra o `index.html` no navegador.

## Publicar no GitHub Pages
1. Envie `index.html` e `README.md` para o repositório.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. O site ficará disponível no endereço mostrado pelo GitHub.
